StageCase

Looper, Clips, Setlist, Lead Sheet, Mixer und Soundkarte für Ableton Live – in einer App am Mac und auf jedem Tablet im Raum.

▶ Rundgang durch alle SeitenInstallierenLive einrichten

Das hier ist die Kurzanleitung. Alles zur Bedienung steht in der App selbst: Menü ❓ Hilfe – mit Suche, auf Deutsch und Englisch, und sie springt zur Seite, auf der du gerade bist.

Was du brauchst

  • Einen Mac mit macOS 12 oder neuer.
  • Ableton Live 12 (empfohlen). Nur mit Live 12 bedient StageCase die Looper selbst – ohne MIDI-Zuweisungen. Unter Live 11 laufen Anzeige, Songs, Clips, Mixer und Soundkarte.
  • Zugang zur Beta: eine Einladung in die GitHub-Organisation LooperPilot (Anfrage an drumset@hennys.de).
  • Optional: KORG nanoKONTROL2, Morningstar MC6 Pro, Roland SPD-SX PRO.

Installieren und aktualisieren

Terminal öffnen (⌘ Leertaste, „Terminal“) und diese Zeile einfügen – sie installiert und aktualisiert:

curl -fsSL https://looperpilot.github.io/install.sh | sh
  1. Beim ersten Mal bei GitHub anmelden

    Das Script zeigt einen Code, kopiert ihn und öffnet die GitHub-Seite – Code einfügen, bestätigen. Fehlt das GitHub-Werkzeug fürs Terminal, holt das Script es selbst.

  2. Alles kommt an seinen Platz

    Die App StageCase nach „Programme“, das Script Stagecase nach ~/Music/Ableton/User Library/Remote Scripts, Vorlage und Demo-Set zu den Live-Vorlagen, die MC6-Pro-Bank nach ~/Music/Ableton/LooperPilot/Presets. Alte LooperPilot-Apps und die drei alten Scripts räumt es weg.

  3. Die App startet

    Erst das Logo, dann die Startseite mit allen Seiten als Kacheln. Tab wechselt jederzeit zwischen Startseite und der zuletzt offenen Seite.

Ohne Terminal: unter LooperPilot/looper-pilot → Releases die Datei StageCase-….zip laden, entpacken und im Ordner sh install.sh ausführen. Gibt es eine neue Version, zeigt die App oben neben der Versionsnummer ⬆ Update.

Ableton Live einrichten (einmalig)

  1. Live neu starten

    Mit ⌘Q beenden und neu öffnen – Remote Scripts liest Live nur beim Start.

  2. Eine Bedienoberfläche

    Einstellungen → Link, Tempo & MIDI: in einer freien Zeile Stagecase wählen, Eingang Stagecase, Ausgang Stagecase. Das ist alles – nanoKONTROL2, MC6 Pro und SPD-SX PRO brauchen keine eigene Zeile, StageCase findet sie selbst (auch später eingesteckt).

  3. Controller nicht doppelt

    In der Liste der MIDI-Anschlüsse bei nanoKONTROL2, MC6 Pro und SPD-SX PRO Track und Remote ausschalten – sie laufen jetzt über StageCase.

  4. Set öffnen

    Ein eigenes Set, die Vorlage LooperPilotTemplate oder das Demo-Set HelpTemplate. Solange in Live noch kein Set offen ist, bietet die Startseite der App „Letztes Set öffnen“, „Neues Set“ und „Demo“ an.

Umstieg von LooperPilot 3.x: die alten Zeilen LooperDisplay, SPD_SX_Pro_Looper und MorningstarClips auf „Kein“ stellen (meist sind sie nach dem Update schon leer). Solange Live noch ein altes Script nutzt, zeigt StageCase oben einen gelben Hinweis.

Tablet und Handy

Extras → 📱 Tablet zeigt Adresse und QR-Code. Mit der Kamera scannen, in Safari öffnen, dann Teilen → Zum Home-Bildschirm – so startet StageCase am iPad wie eine App, ohne Adressleiste. Alle Geräte müssen im selben Netz sein.

Starten, beenden, Probleme

  • Starten: die App StageCase öffnen – aus „Programme“, Launchpad oder Spotlight. install.sh brauchst du nur zum Installieren und Aktualisieren.
  • Fenster schließen lässt StageCase für die Tablets weiterlaufen; ⌥⌘Q beendet es ganz.
  • Keine Verbindung zu Live? Steht Stagecase in den Live-Einstellungen? Wurde Live nach dem Update mit ⌘Q neu gestartet?
  • Protokoll für Fehlerberichte: ~/Library/Logs/Stagecase.log – gern per Mail an drumset@hennys.de.

Loopers, clips, setlist, lead sheet, mixer and audio interface for Ableton Live – in one app on the Mac and on every tablet in the room.

▶ Tour of every pageInstallSet up Live

This is the short guide. Everything about using it lives in the app itself: menu ❓ Help – searchable, in English and German, and it opens at the page you are on.

What you need

  • A Mac with macOS 12 or newer.
  • Ableton Live 12 (recommended). Only Live 12 lets StageCase drive the loopers itself – no MIDI mappings. With Live 11, display, songs, clips, mixer and audio interface work.
  • Beta access: an invitation to the GitHub organization LooperPilot (ask at drumset@hennys.de).
  • Optional: KORG nanoKONTROL2, Morningstar MC6 Pro, Roland SPD-SX PRO.

Install and update

Open Terminal (⌘ Space, “Terminal”) and paste this line – it installs and updates:

curl -fsSL https://looperpilot.github.io/install.sh | sh
  1. Sign in to GitHub the first time

    The script shows a code, copies it and opens the GitHub page – paste it, confirm. If the GitHub command-line tool is missing, the script fetches it.

  2. Everything goes to its place

    The StageCase app to Applications, the Stagecase script to ~/Music/Ableton/User Library/Remote Scripts, template and demo set to Live’s templates, the MC6 Pro bank to ~/Music/Ableton/LooperPilot/Presets. Old LooperPilot apps and the three old scripts are removed.

  3. The app starts

    First the logo, then the start page with every page as a tile. Tab switches between the start page and the page you used last – any time.

Without Terminal: download StageCase-….zip from LooperPilot/looper-pilot → Releases, unzip it and run sh install.sh in the folder. When a new version is out, the app shows ⬆ Update next to its version number.

Set up Ableton Live (once)

  1. Restart Live

    Quit with ⌘Q and reopen – Live reads Remote Scripts only at startup.

  2. One control surface

    Settings → Link, Tempo & MIDI: choose Stagecase in a free row, input Stagecase, output Stagecase. That’s it – nanoKONTROL2, MC6 Pro and SPD-SX PRO need no row of their own, StageCase finds them (also when plugged in later).

  3. No double controllers

    In the MIDI ports list, switch Track and Remote off for nanoKONTROL2, MC6 Pro and SPD-SX PRO – they now run through StageCase.

  4. Open a set

    Your own set, the template LooperPilotTemplate or the demo set HelpTemplate. As long as Live has no set open, the app’s start page offers “Open last set”, “New set” and “Demo”.

Coming from LooperPilot 3.x: set the old rows LooperDisplay, SPD_SX_Pro_Looper and MorningstarClips to “None” (usually they are empty after the update already). While Live still uses an old script, StageCase shows a yellow hint at the top.

Tablet and phone

Extras → 📱 Tablet shows the address and a QR code. Scan it, open it in Safari, then Share → Add to Home Screen – StageCase then starts on the iPad like an app, without the address bar. All devices must be on the same network.

Start, quit, trouble

  • Start: open the StageCase app – from Applications, Launchpad or Spotlight. You only need install.sh to install and update.
  • Closing the window keeps StageCase running for the tablets; ⌥⌘Q quits it completely.
  • No connection to Live? Is Stagecase selected in Live’s settings? Did you restart Live with ⌘Q after the update?
  • Log for bug reports: ~/Library/Logs/Stagecase.log – mail it to drumset@hennys.de.
